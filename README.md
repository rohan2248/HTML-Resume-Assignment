# HTML Resume Page 

This is a simple **HTML Resume Webpage** created using only basic HTML5 elements.  
It represents a personal portfolio/resume layout including skills, experience, projects, education, and contact details.

---

##  Features

- Semantic HTML structure (`header`, `main`, `section`, `footer`)
- About Me section
- Skills list
- Experience table
- Projects description
- Education table
- Contact information
- Copyright footer

---

## 🛠️ Technologies Used

- **HTML5**

(No CSS or JavaScript used — pure HTML structure)
